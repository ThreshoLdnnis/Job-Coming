# Job-Coming · 七城招聘与实习

一个给正在找校招和实习的同学使用的公开招聘索引。收录北京、上海、广州、深圳、苏州、杭州和南京的 **495 条招聘记录**，其中 **17 条**含实习线索。

[打开招聘页面](https://thresholdnnis.github.io/Job-Coming/)

## 使用方法

- 输入公司名或岗位关键词，也可以按城市、方向和实习线索筛选。
- 点 **前往投递** 跳转到原投递入口。部分入口可能需要登录对应招聘平台。
- 已确认可直达官方招聘公告的记录会显示 **官方公告**。
- `index.html` 为可独立打开的静态页面。下载后可在本地浏览和筛选，访问外部投递入口时需要联网。

## 数据来源

信息整理自《27届招聘筛选结果》。每行对应一条招聘记录，一条记录可能列出多个岗位和多个城市。资料日期和截止时间沿用原表，当前招聘状态以招聘方为准。
