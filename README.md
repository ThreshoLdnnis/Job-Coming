# Job-Coming · 七城招聘与实习

面向找校招和实习的同学，收录北京、上海、广州、深圳、苏州、杭州和南京的 **495 条招聘记录**。其中 **17 条**含实习线索，**12 条**附有已核验的招聘公告入口。

[打开招聘页面](https://thresholdnnis.github.io/Job-Coming/)

## 岗位方向

| 方向 | 记录数 | 常见岗位或业务 |

| 金融 | 109 | 银行、证券、基金、审计、风控、投融资 |
| 互联网 | 133 | 电商、用户运营、内容运营、游戏与平台业务 |
| AI | 168 | 大模型、机器学习、算法、智能体和 AI 应用开发 |

同一条公告可能对应多个方向和岗位，方向计数可以重叠。部分标签来自公司行业或招聘原文中的关键词，具体职责以公告为准。

## 使用方法

- 输入公司名或岗位关键词，也可以按城市、方向和实习线索筛选。
- 点 **前往投递** 可打开原表「投递链接」列提供的入口。部分入口需要登录招聘平台。
- 点 **官方公告** 可打开已核验的公告页面。该入口仅在核验通过的记录中显示。
- `index.html` 为可独立打开的静态页面。下载后可在本地浏览和筛选，访问外部投递入口时需要联网。

## 数据来源

公开页面使用《27届招聘筛选结果》的公司、岗位、城市及投递链接。每条记录可能列出多个岗位和城市，具体岗位对应的地点、要求和招聘状态以招聘方为准。页面所列资料日期和截止时间来自原表。
